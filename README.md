# Telegram Group Manager

ربات مستقل خوشامدگویی و راهنمای پایه گروه.

## امکانات نسخه اول
- خوشامدگویی به اعضای تازه‌وارد
- `/rules`: نمایش قوانین پایه
- `/id`: نمایش شناسه گروه
- `/help`: راهنما

این نسخه پیام‌ها را خودکار حذف یا کاربران را مسدود نمی‌کند؛ برای جلوگیری از حذف اشتباه محتوا، مدیریت تهاجمی فعال نشده است.

## تنظیمات مستقل
- `BOT_TOKEN`: توکن اختصاصی ربات مدیریت گروه
- `OWNER_ID`: شناسه عددی مالک
- `BOT_USERNAME`: (اختیاری) نام کاربری بدون @ برای کنترل تطابق توکن

## اجرا
```bash
export BOT_TOKEN='توکن اختصاصی'
export OWNER_ID='شناسه عددی مالک'
python bot.py
```
یا با Docker:
```bash
docker build -t telegram-group-manager .
docker run -d --restart unless-stopped -e BOT_TOKEN -e OWNER_ID -e BOT_USERNAME telegram-group-manager
```

ربات برای دریافت رویداد اعضای جدید باید به گروه اضافه شود. برای مدیریت کامل‌تر، مجوز مدیر فقط در صورت نیاز و با حداقل دسترسی اعطا شود. این برنامه long polling دارد و به Python دائمی (VPS/کانتینر) نیاز دارد.
